# HouseMind REST API Specification

All protected endpoints require a valid Firebase ID token passed via the HTTP header:
`Authorization: Bearer <ID_TOKEN>`

---

## 1. Household Profile, Privacy & Data Governance

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/household/profile` | Retrieves the authenticated user's profile and localization config |
| `PUT` | `/api/household/profile` | Updates household profile, country, currency, timezone, and specs |
| `GET` | `/api/household/privacy-center` | Returns data inventory (user vs demo), connected source states, and AI privacy boundaries |
| `GET` | `/api/household/data-sources` | Legacy alias for privacy and source metadata console |
| `POST` | `/api/household/demo-seed` | Seeds deterministic starter dataset for the calling user |
| `POST` | `/api/household/demo-remove` | Safely purges all `isDemo: true` records, preserving user-authored data |
| `POST` | `/api/household/reset-data` | Completely resets user data (requires `{ confirmPhrase: "DELETE MY DATA" }` or `{ confirm: true }`) |

---

## 2. Expenses & Assets

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/household/expenses` | Lists all recurring and scheduled expenses |
| `POST` | `/api/household/expenses` | Creates a new expense record |
| `PUT` | `/api/household/expenses/:id` | Updates an existing expense |
| `DELETE` | `/api/household/expenses/:id` | Deletes an expense |
| `GET` | `/api/household/assets` | Lists all registered household assets and equipment |
| `POST` | `/api/household/assets` | Registers a new asset |
| `PUT` | `/api/household/assets/:id` | Updates asset status, warranty, or maintenance log |
| `DELETE` | `/api/household/assets/:id` | Deletes an asset |

---

## 3. Financial Transactions & Intelligence

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/transactions` | Retrieves transactions with optional type/category/search filters |
| `POST` | `/api/transactions` | Creates a new financial transaction |
| `PUT` | `/api/transactions/:id` | Updates an existing transaction |
| `DELETE` | `/api/transactions/:id` | Deletes a transaction |
| `GET` | `/api/transactions/summary` | Calculates real-time financial metrics (Net Cash Flow, Savings Rate) |

---

## 4. Document Intelligence & Extraction

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/documents` | Lists uploaded financial and household documents |
| `POST` | `/api/documents/upload` | Uploads and parses statements/invoices via Gemini Vision/OCR |
| `POST` | `/api/documents/:id/confirm` | Confirms extracted draft transactions into the active ledger |
| `DELETE` | `/api/documents/:id` | Deletes a document record |

---

## 5. What-If Financial Simulations

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/scenarios` | Lists all created what-if financial decision simulations |
| `POST` | `/api/scenarios/calculate` | Computes projected metrics for a scenario input without saving |
| `POST` | `/api/scenarios` | Creates and persists a scenario simulation |
| `PUT` | `/api/scenarios/:id` | Updates scenario parameters and recalculates projections |
| `POST` | `/api/scenarios/:id/duplicate` | Duplicates a scenario for comparative branch testing |
| `POST` | `/api/scenarios/:id/explain` | Generates Gemini AI opportunity cost & strategic guidance |
| `POST` | `/api/scenarios/compare` | Compares 2-4 scenarios side-by-side |
| `DELETE` | `/api/scenarios/:id` | Deletes a scenario simulation |

---

## 6. Gemini Copilot & Household Intelligence

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/copilot/chat` | Sends a message to the grounded Gemini 2.5 Copilot |
| `GET` | `/api/copilot/conversations` | Lists saved chat sessions |
| `GET` | `/api/copilot/conversations/:id` | Retrieves full conversation history |
| `DELETE` | `/api/copilot/conversations/:id` | Deletes a conversation |
| `GET` | `/api/intelligence/insights` | Retrieves diagnostic insights generated by Household Investigator |
| `POST` | `/api/intelligence/investigate` | Triggers a fresh deep diagnostic scan across all household data |
| `PATCH` | `/api/intelligence/insights/:id/status` | Updates insight resolution status (`viewed`, `resolved`, `dismissed`) |
